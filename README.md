# eMudraImpacts

Inventory of Indian government websites whose TLS certificates will break after the
**eMudhra CA compromise / emSign G1–G3 root removal from browser & OS trust stores**.

> **Deadline: Chrome removes `emSign ECC Root CA - G3` on 2026-10-27.**
> Microsoft has blocked the compromised intermediates since 2026-10-20 (any client
> enforcing CRLs on the Sectigo AAA cross-sign is already failing).

Full incident background, exact intermediate/root IOCs and the vendor timeline:
[notes/incident-brief.md](notes/incident-brief.md).

## Scope — expanded universe (10,808 domains)
- **9,670 domains** from the registry dump (7,259 `*.gov.in` + 2,454 `*.nic.in`,
  [cyb3r-n3rd gist](https://gist.github.com/cyb3r-n3rd/f4e50f7c25eaa676bb99efba9c8619bf)).
- **+278 domains** from a full IGOD (india.gov.in web-directory API) dump across all 36
  states/UTs — 9,487 directory entries (`scripts/igod_dump.py`, full dump in `results/igod-dump.csv`).
- **+1,000 domains** from a link crawl (`scripts/discover_links.py`): homepage, `robots.txt`
  and `sitemap.xml` of every TLS-reachable host harvested for cross-referenced
  `*.gov.in`/`*.nic.in` domains (9,500+ hostnames seen).
- Merged universe: `data/gov-domains.txt` ∪ `data/igod-domains.txt` ∪ `data/discovered-domains.txt`.

## Layout
```
data/          seed lists, expansion provenance, IOC JSONs from the incident site
scripts/       scan_tls.py (scanner), igod_dump.py, discover_links.py,
               rollup.py, merge_results.py, gen_site.py
results/       impacted.csv, scan-all.csv, g1-impact-list.csv, g3-impact-list.csv
               impacted-domains-summary.csv, chains/*.pem (per-scan dirs: main/,
               expand/, vhost-probe*/, rebuild/ — root files composed by merge_results.py)
docs/          GitHub Pages site (generated by gen_site.py)
notes/         incident-brief.md
```

## Usage
```bash
SCAN_OUT=results/main python3 scripts/scan_tls.py data/gov-domains.txt   # universe scan
SCAN_OUT=results/expand python3 scripts/scan_tls.py data/new-domains.txt # expansion scan
python3 scripts/merge_results.py     # compose root deliverables from per-scan dirs
python3 scripts/rollup.py            # g1/g3 impact lists + per-domain summary
python3 scripts/gen_site.py          # regenerate docs/ (Pages)
SCAN_WORKERS=80 python3 scripts/scan_tls.py data/gov-domains.txt   # full scan (~30 min)
```
Per-scan outputs always go to `results/<name>/`; never write a new scan directly into
`results/` (root files are composed by `merge_results.py`).

## Findings (scan of 2026-10-24, universe expanded same day)

**533 HTTPS endpoints across 247 gov.in / nic.in domains present eMudhra/emSign TLS**
(lists: **G1 impact list** `results/g1-impact-list.csv` · **G3 impact list** `results/g3-impact-list.csv`
· per-domain summary `results/impacted-domains-summary.csv` · chain evidence in `results/chains/`).

- **G3 impact list: 0 endpoints.** No scanned gov site chains to the 8 compromised intermediates
  (`EM DV/OV/EV TLS CA - G3B/G3C`), so the 2026-10-27 Chrome removal hard-breaks none of them.
- **G1 impact list: all 533 endpoints**, split across two trust paths:
  - 129 endpoints — `emSign SSL CA - G1` → legacy `emSign Root CA - G1` (direct)
  - 402 endpoints — `EM * TLS CA - G2A-1` → `emSign Root TLS CA - G1` (Microsoft-only 2024 root) cross-signed by legacy G1
  - 2 endpoints — legacy eMudhra EV intermediate
  All work today; they break if Chrome/Mozilla remove legacy `emSign Root CA - G1` (under evaluation),
  and eMudhra is exiting public TLS regardless — planned reissue recommended.
- Expansion added 16 new impacted domains, notably `nha.gov.in` (National Health Authority,
  incl. `sso.nha.gov.in`), `ipindiaonline.gov.in`, `dghindia.gov.in`, `jkhc.gov.in`,
  `recindia.nic.in`, `pariksha.nic.in`, `arunachalplan.gov.in`, `sampada-mofpi.gov.in`.
- 13 endpoints currently time out on re-check (NIC throttling) but carry saved chain
  evidence from the initial scan and are retained in the list.

## Detection logic
| Verdict | Meaning |
|---|---|
| `CONFIRMED-COMPROMISED-INT` | leaf (or chain) issued by one of the 8 compromised intermediates (`EM DV/OV/EV TLS CA - G3B/G3C`, `EM OV CS CA - G3B/G3C`) — **must reissue** |
| `EMSIGN-FAMILY` | issued by another eMudhra/emSign intermediate (e.g. legacy `emSign Root CA - G1` chains) — in the G1/G3 removal blast radius, reissue recommended |

Non-eMudhra issuers (Sectigo, Let's Encrypt, NIC CCA chains, expired/self-signed…) are
recorded in `results/scan-all.csv` but are out of the emSign blast radius.

## Known limitations
- Only :443/:8443 HTTPS on apex + www is probed; additional vhosts of impacted domains
  can be enumerated from CT logs (crt.sh) once the impacted domain set is known.
- Shell/TLS on other ports (SMTP, RDP over 443-only appliances) is out of scope.
- The gist is the domain universe of record; domains registered after its snapshot
  date are not covered. `scripts/ct_enum_hostnames.py` enumerates every CT-logged
  hostname of the impacted domains via crt.sh for a later re-run (crt.sh was
  rate-limiting/502ing during this session's runs, so only apex+www + a common-vhost
  prefix probe were live-scanned).
